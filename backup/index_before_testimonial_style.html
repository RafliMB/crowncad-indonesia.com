Core Capabilities:
Powering Your CAD Workflow

• Data compatibility and collaboration • Part design • Assembly design • Drawing design

• Multi-user collaborative design • Version management • Team coordination tools • Secure project sharing

Sketching

  • •Supports the creation of polylines, arcs curves, slots, and more.
  • •Enables quick dimensioning and geometric constraints.
  • •Provides editing tools for fillets chamfers, trimming, offsetting, and more.
  • •Includes inspection and repair functions.

Part Design

  • •Supports complex curve/surface geometric modeling.
  • •Offers feature-based parametric solid modeling.
  • •Allows direct modeling for both parametric and non-parametric models.
  • •Delivers powerful hybrid surface/mesh modeling capabilities.

Assembly Design

  • •Supports both top-down and bottom-up assembly design.
  • •Enables efficient component mating.
  • •Ensures real-time synchronization between assemblies and parts.
  • •Provides interference checks between components.

Drawing

  • •Automatically generates projection views from 3D models.
  • •Offers international standard-compliant drafting methods.
  • •Supports automatic dimensioning.
  • •Maintains synchronization between 2D and 3D models.

Data Compatibility

  • •Imports standard formats such as IGES, STEP, and Parasolid.
  • •Directly reads models from CATIA, NX (UG), Creo, SOLIDWORKS, Inventor, Revit, AutoCAD, and more.
  • •Exports models to IGES, STEP, CATIA, NX (UG), SOLIDWORKS, AutoCAD, STL, and more.

Sheet Metal Module

  • •Provides basic sheet metal features (e.g., louvers, stamping).
  • •Supports rapid unfolding and folding to streamline design-to-production workflows.

Weldment Module

  • •Offers a library of standard structural profiles.
  • •Enables quick creation of 2D and 3D sketch paths.
  • •Allows fast modification of corner connection styles.
  • •Supports exporting weldment cut lists.

MBD

  • •Enables direct 3D annotations and notes for seamless communication between users and manufacturers.
  • •Supports transferring PMI (Product Manufacturing Information) to 2D drawings to boost drafting efficiency.
  • •Reads and imports MBD data from external models for collaborative design.

Animation

  • •Realistically simulates mechanism motion based on assembly mating relationships.
  • •Allows users to define motion states freely via time-based keyframes.
  • •Supports AVI/MP4 video output to show mechanism & speed up decisions.

Version Management

  • •Ensures data security through encrypted cloud storage and transmission.
  • •Tracks complete model editing history, allowing users to roll back to any historical version for editing.
  • •Implements version control via version nodes and branches, simplifying design reviews.

Collaboration

  • •Cloud-Powered Collaboration: Innovation, security, and efficiency across devices.
  • •Team Collaboration: Streamlined teamwork via team creation.
  • •Secure Collaboration: Strict permission controls and versioning to protect data integrity.
  • •Efficient Collaboration: Minimizes data transfer overhead and combines real-time communication for instant responsiveness.
  • •Cross-platform Collaboration: Seamless design and review across PCs, smartphones, tablets, smart displays, and other devices.
